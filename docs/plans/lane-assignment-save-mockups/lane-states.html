Lane page: new states

Everything else on the page is as built (division strip, unassigned list, pairs). Only the parts below change.

1. Status line: live

Live: changes by others show here as they happen.

Sits above the division strip, right-aligned on wide screens. Polite live region; it announces only when the state changes.

2. Status line: reconnecting, and off

Reconnecting… The page refreshes when it is back.

Live updates are off. Your signed-in session may have ended.

"Off" shows when the browser gives up (a 401 or 403 closes the stream for good). Saving still works.

6. Refused: the session is complete

This squad is complete. Lanes cannot change.

Another desk completed the squad while this page was open. The page refetches and drops to read only, with the existing line "This squad is complete. Lanes cannot change."

7. Other refusals and failures

That bowler is no longer in this squad. The page was refreshed.
Could not save the move. Check your connection and try again.
You are not allowed to move bowlers.

The last one is for a score keeper, who can see the lanes live but holds no lanes.assign. The drag handles and Assign buttons do not show to that user, so this is the fallback for a role change mid-session.

8. Read only for a score keeper

Live: changes by others show here as they happen.

No drag handles, no Move or Assign button, no extra line. Watching is the whole job. A complete session shows the existing line and opens no stream, so there is no status line either.
