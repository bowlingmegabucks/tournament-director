Office Check: __________

How a sheet is selected: its checkbox (all start checked). The "Find a bowler" box narrows the list the way the Registrations filter does (every word starts the first name, last name, or division, D-49 style). "Select shown" checks the sheets in view and leaves the rest as they are, "Select all" and "Clear" act on every sheet, and a filter never unchecks anything, so a checked sheet that is hidden still prints. The count in the bar and on "Print selected" always counts every checked sheet, shown or not. A sheet that is not selected is dimmed and says "Not printing", so color is never the only cue. Print all ignores the checkboxes.

Why the lanes cannot change: the API returns each bowler's cross worked out from every saved assignment, and the page only chooses which finished sheets to print. In this example Maria's sheet starts on 3A and moves through 6A, 9A, 12A, 13A, 16A on the same lanes whether or not Dana's sheet prints.
