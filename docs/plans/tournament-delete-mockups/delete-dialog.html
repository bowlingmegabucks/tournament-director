Delete tournament: the dialog

Opens from the Delete button on the overview (D-136). A native <dialog> opened with showModal(), like the edit confirm dialog. Cancel has focus first and Escape closes it. Delete stays disabled until the typed name matches (trimmed, any case). The request is DELETE /v1/tournaments/{id}.

1. Opened: name not typed

Delete is disabled. The name is shown under the box to copy by eye.

Delete this tournament?

This deletes Northeast MegaBuck$ Open 2026 for good. It cannot be undone.

2. Name typed

Delete is enabled. Typing is checked as you go; nothing is sent until you press Delete.

Delete this tournament?

This deletes Northeast MegaBuck$ Open 2026 for good. It cannot be undone.

3. The API asks first: registrations exist (D-134)

The API answered 409 with a warning and deleted nothing. The text is replaced with what will go; the typed name stays. The button now says "Delete anyway" and sends ?confirmWarnings=true.

Delete this tournament?

12 registrations, 4 divisions, 3 squads, and 1 sweeper will be deleted, with their lane assignments and payment records. The bowlers stay.

This cannot be undone.

4. Only divisions and squads (no registrations)

No API warning, so state 2 is all there is. Nothing else to confirm.

5. Deleting

Both buttons are disabled while the request runs.

Delete this tournament?

6. Refused (D-133)

The API answered 409 with errors. The dialog closes and an error toast stays until dismissed, with the API's reason. The tournament is still there. Three possible messages (several can show together):

3 bowlers paid online. Remove their registrations first.

Scores are saved, so this tournament cannot be deleted.

This tournament is complete and cannot be deleted.

With more than one reason, the toast lists each on its own line.

  • Scores are saved, so this tournament cannot be deleted.
  • 3 bowlers paid online. Remove their registrations first.

7. Any other failure

The dialog stays open and says why, so you can try again.
