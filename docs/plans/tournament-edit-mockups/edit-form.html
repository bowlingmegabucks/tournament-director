Edit tournament: the form

Route /tournaments/{id}/edit. The page is reached from an Edit link on the overview, shown only to users with tournaments.write (D-19, D-102). Every state is below. Dashed grey fields are locked (D-128); the line under a field says why. A line starting "Asks you to confirm" tells the director up front which fields will raise the warning dialog (D-129).
